## Project Name
Earthly Innovations
## About
Earthly Innovations is a company website for Earthly Innovations LLC, showcasing advanced CSS styling for a visually engaging design. The site features themed sections inspired by locations such as Paris, France, and Aztec, Mexico, with motivational and philosophical content emphasizing beliefs, perseverance, and personal growth. Built using HTML for structure, CSS for styling (including custom fonts and animations), and basic JavaScript for interactive elements like dynamic title and image changes. The layout includes a header with navigation, a main grid-based content area, and a footer.
## Prerequisites
To run this project you need a modern web browser installed on your system.
No additional libraries are required.
## Features
Earthly Innovations includes these features:

-Themed grid sections for locations like Paris, France and Aztec, Mexico, with background images and overlaid text such as "The buy of a lifetime."

-Motivational paragraphs with philosophical quotes on perseverance, beliefs, and divine will, styled with custom fonts like Cinzel Decorative.

-Header with logo, navigation bar (Home, About Us, Scheduling), and a rainbow-animated "Contact Us" button linking to Google.

-Interactive JavaScript: A button that changes the title text to "Vous" in red and swaps an image source.

-CSS animations: Hover effects on navigation links with color transitions and rainbow background on the header button.

-Custom Google Fonts: Raleway, Parisienne, Herr Von Muellerhoff, Cinzel Decorative, and Montserrat for typography.

-Responsive elements like grid layouts for content and background images with positioning.

## Usage
Ensure all associated assets (images in the Images folder, including Favicon, Logo Designs, and Images subdirectories, and the style.css file) are downloaded with the repository. Open the index.html file in using a live server or a modern web browser from the command line or file explorer: open index.html (on macOS) or simply double-click the file. Interact with the "Click to Change Title" button to see JavaScript in action.
